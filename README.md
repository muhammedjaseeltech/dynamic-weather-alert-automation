# Dynamic Weather Alert Automation

A reusable weather automation workflow built with n8n.

## Overview

This workflow allows a user to enter a city dynamically through an n8n Form. It fetches real-time weather data using WeatherAPI and sends the weather information automatically through Telegram.

## Workflow

Form Trigger → HTTP Request → Edit Fields → Telegram

## Features

- Dynamic city input
- Real-time weather data
- Reusable workflow
- Automatic Telegram weather message
- Built using n8n and WeatherAPI

## Tools Used

- n8n
- WeatherAPI
- Telegram Bot
- Git
- GitHub

This project was created as part of my AI Automation learning journey to practice dynamic inputs, API integration, data processing, and automated messaging.
